# User Onboarding Strategy

New users can begin using StudySprint AI in less than two minutes.

The onboarding process:

1. Open the website.
2. Enter exam details.
3. Add subjects.
4. Select priority and preparation level.
5. Choose a preferred language.
6. Select an AI provider.
7. Generate the personalized study plan instantly.

No account creation is currently required, reducing friction for first-time users.
